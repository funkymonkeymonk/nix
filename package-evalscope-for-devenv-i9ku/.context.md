# Goal
Add a Nix package under packages/benchmarks/ and make it available in the devenv, following the pattern established by packages/benchmarks/lm-eval and packages/benchmarks/lighteval.

## Acceptance Criteria
- [ ] Package builds with nix build .#packages.aarch64-darwin.<name>
- [ ] Installed in devenv.nix packages
- [ ] One devenv task added under benchmark:<name> that runs a quick task against the local vllm-mlx endpoint
- [ ] devenv tasks run check:lint passes
- [ ] devenv tasks run test passes

## Files
- packages/benchmarks/<name>/default.nix
- overlays/default.nix
- flake.nix
- devenv.nix
