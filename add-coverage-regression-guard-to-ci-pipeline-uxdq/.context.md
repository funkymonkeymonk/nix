## Resolution

While implementing this, discovered and fixed a real bug: the module
discovery helper mixed path-string representations (store path vs
filesystem path), silently corrupting the untested-modules report
(every module always appeared untested regardless of real test
coverage). Fixed the path bug, corrected 3 stale testedModules entries,
and established the real baseline (46%, not the previously-bogus 50%).

Added minCoveragePct = 46 with an assertion that fails the build if
coverage regresses below it. Verified RED (threshold set to 99% fails
with clear message) and GREEN (real threshold passes).
