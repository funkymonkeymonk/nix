## Resolution

Added tests/test-library.nix covering mkDarwinSystem and mkNixosSystem
via real flake inputs + real archetype modules (base-darwin.nix).
Covers hostName, overlays, allowUnfree, home-manager wiring, opnix
shared module presence, and override priority (mkOverride 50).

Note: opnix module presence had to be verified via the
programs.onepassword-secrets option rather than builtins.elem on
the module value directly, since Nix function/lambda values are not
reliably comparable with == (f == f evaluates to false for lambdas).

Wired mk-darwin-system / mk-nixos-system into flake.nix checks,
matching the existing core-bootstrap/phase3-zero/phase4-darwin-server
pattern.
