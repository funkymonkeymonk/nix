# Goal
Make devenv.nix consume the canonical foundation/developer role package definitions instead of maintaining a parallel library/dev-base.nix list. Preserve devenv-only Nix tooling as explicit devenv additions.

# Scope
- Source shared package definitions from modules/roles/foundation-packages.nix and the appropriate developer package definitions.
- Keep formatter, linter, Nix introspection, CI, and benchmark tools that are specific to developing this repository in devenv.nix.
- Compare the before/after package closure and preserve every tool currently available in the devenv shell.
- Remove library/dev-base.nix and modules/darwin/dev-base.nix only after all references are gone.

# Out of scope
Do not add a deployable or provisionable core machine in this yak. That is a separate design decision.
