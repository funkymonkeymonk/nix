# Goal
pi errors with "Stream ended without finish_reason" on tool calls via vllm-mlx + gemma4-31b.

# Root cause (verified)
Engine's terminal output (finished=True, bare <turn|>) is swallowed by a parser `continue`
in stream_chat_completion, so no SSE chunk carries finish_reason. NON-DETERMINISTIC on
current main build: bites when the model keeps its thought channel open through the tool
call. Live daemon already runs the main build and still fails — a plain update does NOT fix it.
