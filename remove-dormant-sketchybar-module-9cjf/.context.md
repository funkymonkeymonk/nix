# Goal
Remove the sketchybar home-manager module and its plumbing -- it's not enabled on any host, no clear feature direction was chosen (see closed yak 'create a sketchybar that shows open workspaces...'), and the base module has known bugs from a closed-not-merged PR (#280: sketchybarrc missing a shebang so sketchybar likely can't even fork_exec it as shipped; require() path issues since Lua files are written as separate pkgs.writeText store paths instead of one CONFIG_DIR).

# Background
myConfig.sketchybar.enable is not set true on any host (hosts/wweaver, hosts/megamanx checked). The module exists (modules/home-manager/sketchybar/) with real test coverage (tests/test-sketchybar.nix) but has never been exercised on a live system. A dead flake input (aerospace-sketchybar, github:zmre/aerospace-sketchybar-nix-lua-config) was added for an alternate approach documented in the module's README but never wired into any output.
