## Resolution

Deleted modules/services/openclaw/legacy.nix and darwin.nix. Both
defined a hand-rolled services.openclaw option never enabled anywhere
in the repo (real deployments use programs.openclaw / the upstream
nix-openclaw flake's services.openclaw-gateway). darwin.nix was fully
orphaned; legacy.nix was pulled in transitively via default.nix into
zero/zero-v2.

Removed the associated openclawOptionsTest (tested legacy.nix's option
surface directly) and the openclaw-options check name from
tests/default.nix, flake.nix, and devenv.nix.

Verified via nix eval that zero/zero-v2 still evaluate correctly with
services.openclaw-gateway present, services.openclaw gone, and
myConfig.openclaw (shared.nix) unaffected.
