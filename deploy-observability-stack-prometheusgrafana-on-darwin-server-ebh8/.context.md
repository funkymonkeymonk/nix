# Goal
Deploy a full observability stack (metrics + logs) on protoman (darwin-server) using NATIVE nixpkgs packages wired via launchd.daemons -- matching this repo's own established Darwin service pattern (see modules/services/searxng/darwin.nix, vane, bifrost, caddy, vllm-mlx). NOT via Colima/Docker -- Will explicitly wants to avoid that (2026-08-23). Merges the previously-separate log-aggregator and Prometheus/Grafana yaks, which conflicted on the same file.

# Design
Each tool gets its own launchd.daemons entry, following the exact pattern in modules/services/searxng/darwin.nix (command = "${pkgs.X}/bin/X-binary"; serviceConfig = { KeepAlive/RunAtLoad/WorkingDirectory/StandardOutPath/StandardErrorPath };). Config files (prometheus.yml scrape targets, loki config, vector config, grafana provisioning) written via a script-based launchd daemon (mkdir + printf config + exec, matching the 'script' pattern documented in AGENTS.md) rather than Docker volumes.

New modules, one per service, following this repo's existing modules/services/<name>/darwin.nix convention:
- modules/services/prometheus/darwin.nix -- scrapes node-exporter (self) + any other configured targets
- modules/services/grafana/darwin.nix -- provisioned with Prometheus + Loki as datasources
- modules/services/loki/darwin.nix -- uses grafana-loki package
- modules/services/vector/darwin.nix -- ships host system logs (log show / unified logging) to Loki; a second Vector config note needed for shipping MicroVM logs to host (MicroVMs already have network access to host at 192.168.83.1 per original yak's notes)
- modules/services/prometheus-node-exporter/darwin.nix (or fold into prometheus module) -- exports host metrics

# Acceptance Criteria

- [ ] Prometheus scraping node-exporter (host metrics) + MicroVMs where feasible
- [ ] Grafana has Prometheus AND Loki wired as datasources, with at least one basic dashboard
- [ ] Vector on host ships system logs to grafana-loki; document whether/how MicroVM logs get forwarded (network path already exists at 192.168.83.1)
- [ ] Prometheus + Loki bound to internal network only (192.168.83.0/24); Grafana reachable via Tailscale
- [ ] Basic alert rules for critical services (1Password Connect, MicroVMs) -- requires prometheus-alertmanager wired up too; Alertmanager routing target (Matrix/Discord webhook) TBD -- flag back if credentials needed and not available
- [ ] Log retention policy configured (7 days default, per original yak notes)
- [ ] devenv tasks run check:lint && devenv tasks run test:all pass
- [ ] Manually verified running on protoman after deploy (cannot be fully validated in CI -- launchd services require the real host; this is expected and acceptable per the original @needs-human note)
