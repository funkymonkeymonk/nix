## Problem
Discovered while implementing mergiraf (2026-07-27):
modules/common/users.nix sets `programs.git.settings` (user name/email,
GPG/SSH commit signing via 1Password, allowedSignersFile) for every
user's home-manager config, but never sets `programs.git.enable = true`.
home-manager's programs/git.nix gates its ENTIRE config block
(including settings -> ~/.gitconfig generation) behind
`mkIf cfg.enable`. Since enable defaults to false and is never set
true anywhere in this repo, none of this git config -- including commit
signing -- actually applies. No ~/.gitconfig file is generated at all.

## Evidence
```
nix eval .#darwinConfigurations.wweaver.config.home-manager.users.wweaver.programs.git.enable
# => false

nix eval .#darwinConfigurations.wweaver.config.home-manager.users.wweaver.home.file
# does not contain .gitconfig
```

## Likely Fix
Add `programs.git.enable = true;` alongside the existing
`programs.git.settings = {...}` block in modules/common/users.nix.
