## Resolution

Added tests/test-cross-platform-guards.nix. Key insight: existing
test-roles.nix only checks EXPECTED packages are present, never that
Darwin-only/Linux-only branches stay absent on the wrong platform.
Since myConfig.isDarwin is readOnly and computed from
pkgs.stdenv.hostPlatform.system, built a fake Linux-flavored pkgs
(just overriding the hostPlatform.system string, no real
cross-compilation) fed through tests/stubs.nix.

Covers desktop (Linux gets element-desktop+vivaldi, Darwin doesn't),
entertainment (isNixOS module-definition-time guard correctly absent
on both platforms outside a real NixOS tree), and creative (control
case: platform-independent packages match on both).

Added as a follow-up commit on the already-open overlay-package-tests
PR (#376) since it touches the exact same devenv.nix/flake.nix/
tests/default.nix lines.
