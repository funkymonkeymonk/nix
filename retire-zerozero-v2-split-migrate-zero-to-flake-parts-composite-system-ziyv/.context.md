# Scope decision
- Zero-only pilot: flake-parts wired minimally at the top of flake.nix via
  `flake-parts.lib.mkFlake`. Every other host stays defined exactly as
  today inside the `flake = { ... }` passthrough attribute — no other
  host's derivation changes.
- `zero` moves to a new flake-parts module, `library/machines/zero.nix`,
  imported via `mkFlake`'s `imports`.
- No hardware switch performed by any agent — that decision belongs to
  Will after reviewing a closure diff (see spec).
