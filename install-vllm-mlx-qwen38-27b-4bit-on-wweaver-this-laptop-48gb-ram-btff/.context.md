## Why 4-bit, not 8-bit

MegamanX uses Qwen3.8-27B-8bit (estimatedMemoryGb: 28) because it's a dedicated
128GB Mac Studio. wweaver is a MacBook Pro (M4 Pro, 48GB total unified RAM) that
also runs a browser, IDE, and everything else day-to-day. Budgeting 28GB+ for a
single model on a 48GB laptop leaves too little for the rest of the working set.
Use the 4-bit checkpoint instead: `mlx-community/Qwen3.8-27B-4bit` (~17-18GB on
disk per the source article). It's already pre-fetched as a Nix overlay package
(`qwen3_8-27B-4bit` in `overlays/default.nix`) — no new fetchModel derivation
needed; `resolveModelPath` in `modules/services/vllm-mlx/lib.nix` already maps
this HF path to the overlay automatically.

## Proposed config (add to hosts/wweaver/default.nix, mirroring hosts/megamanx/default.nix)

```nix
myConfig.vllmMlx = {
  enable = true;
  server = { host = "0.0.0.0"; port = 8300; };
  memoryBudgetGb = 24;          # conservative starting point for 48GB total RAM
  contention = "preempt";
  models."qwen3.8-27b" = {
    path = "mlx-community/Qwen3.8-27B-4bit";
    type = "lm";
    estimatedMemoryGb = 18;
    preload = true;
  };
  enableAutoToolChoice = true;
  toolCallParser = "qwen";
  reasoningParser = "qwen3";
  maxKvSize = 65536;            # half of MegamanX's 131072; see benchmark-tuning yak
  timeout = 600;
  logLevel = "INFO";
  enableMetrics = true;
  # No MTP yet in this first pass -- see the follow-up "Add MTP speculative
  # decoding" yak once base memory headroom is confirmed on real hardware.
};
```

## Scope notes

- Do NOT add the full Caddy/dnsmasq/Bifrost gateway stack in this yak unless the
  user wants wweaver to be a second full "internal" gateway host — start with
  vllm-mlx serving directly on :8300. Whether to layer Bifrost/vane/Caddy on top
  is a separate decision; note it as an open question when implementing.
- Follow modules/services/vllm-mlx/darwin.nix wiring pattern (this option already
  exists at the schema level for every darwin host that imports the module —
  check whether hosts/wweaver/default.nix's archetype import chain already pulls
  in modules/services/vllm-mlx/darwin.nix; if not, add the import).
- Verify Prometheus scrape config (modules/services/prometheus/darwin.nix) if/when
  wweaver also runs prometheus; not required for this yak.
