# Goal
Replace the hand-maintained `docs/reference/options.md` with a generated document derived from the actual `myConfig.*` option definitions in Nix code, so the reference can never rot out of sync with the modules.

## Prerequisites
- None. The generator must walk the loaded module tree (all loaded modules' `options.myConfig` sub-trees), not assume a single-file layout — options are declared across `modules/common/options.nix` plus owning modules (onepassword, obsidian, motd, charm, zellij, syncthing, llm-client, agent-user, cachix, role modules).

# Background
- `docs/reference/options.md` (226 lines) is manually written and already stale: it documents a subset of options and has no generator behind it.
- `scripts/docs-update.sh` already generates `roles.md`, `tasks.md`, and `skills.md` from source; options.md is the odd one out.
- The diataxis-docs skill requires frontmatter (title/description/type: reference/audience) on reference docs — the generator must emit it.

# Acceptance Criteria
- [ ] A generator (Nix walk function, e.g. `scripts/generate-options-doc.nix`) walks the loaded config's `options.myConfig` tree and emits `docs/reference/options.md` with frontmatter, sorted, grouped by domain
- [ ] Every `myConfig.*` option in the loaded tree appears in the doc with: path, type, default, description
- [ ] Submodules are documented recursively (e.g. `myConfig.users[].name`)
- [ ] A devenv task (e.g. `docs:generate-options`) runs the generator
- [ ] `docs:all` / `docs:update` in devenv.nix includes options.md generation
- [ ] A CI/check assertion fails if the checked-in `docs/reference/options.md` is stale (regenerate and diff)
- [ ] `devenv tasks run check:lint` and `devenv tasks run test:build-checks` pass
- [ ] The generated doc keeps the existing style: markdown tables per option group, matching the current file's shape

# Files
- `scripts/generate-options-doc.nix` (new — walk function + markdown emitter)
- `devenv.nix` (add task, wire into docs:all)
- `docs/reference/options.md` (regenerated output)
- `flake.nix` or `tests/` (stale-doc check)

# Notes
- Use `nix eval` on a loaded config (any target) to get the option tree; walk with a function handling submodules, defaults, and readOnly options.
