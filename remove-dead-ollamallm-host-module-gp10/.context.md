# Goal
Remove the ollama service module and llm-host role -- ollama is no longer in use, and the module cannot be tested via nixosTest anyway (Darwin-only, launchd/Homebrew, no systemd/nixpkgs dependency).

# Background
Discovered while refining VM/e2e test backlog items: no host currently sets `myConfig.ollama.enable = true` or `myConfig.roles.llm-host.enable = true` (checked hosts/wweaver, hosts/megamanx, all targets/). hosts/megamanx/default.nix does reference `vane.ollamaUrl = "http://localhost:11434"` -- unclear if this is live wiring to a still-running ollama instance outside the Nix-managed toggle, or a dangling default. Verify before removing.
