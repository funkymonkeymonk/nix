## Context
PR #441 (feat: replace vllm-mlx + vane stack with oMLX + Bifrost) makes `myConfig.opencode.model` default to "local-bifrost/omlx/qwen3.8-27b" in:
- library/lib/mk-user.nix (affects ALL hosts using mkUser, incl. NixOS type-server/type-server-arm/type-desktop/zero)
