## What to do
The pre-fetched overlay `qwen3_8-27B-MTP-4bit` (mlx-community/Qwen3.8-27B-MTP-4bit)
already exists in overlays/default.nix, matching the 4-bit target checkpoint.
Add to hosts/wweaver/default.nix's vllmMlx block (same pattern as MegamanX):

```nix
mllmDraftModel = "mlx-community/Qwen3.8-27B-MTP-4bit";
mllmDraftKind = "mtp";
mllmDraftBlockSize = 3;   # start at MegamanX's default; tune per article's
                          # guidance on MTP block size vs acceptance rate
```

Note: setting `mllmDraftModel` forces single-model mode (no `--models-config`),
which is fine here since wweaver only serves one model.

Per the source article, MTP speculative decoding is one of the launch flags that
separates a "sluggish setup from one running 2-3x faster on identical hardware" —
this is expected to be the single highest-leverage change for interactive coding-
agent latency on this laptop.
