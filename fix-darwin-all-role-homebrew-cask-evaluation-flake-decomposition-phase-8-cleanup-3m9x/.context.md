# Goal
Make simultaneous Darwin role evaluation valid without losing casks from either the base homebrew role or the entertainment role.

# Root symptom
All-systems flake evaluation currently fails because homebrew.casks receives conflicting list definitions from modules/roles/homebrew.nix and modules/roles/entertainment.nix.

# Scope
- Preserve the existing casks from both roles.
- Use the module-system merge semantics appropriate for additive role-owned lists.
- Add regression coverage for all relevant Darwin roles enabled together.
- Keep Linux evaluation and NixOS role behavior unchanged.

# Verification
- Darwin role evaluation passes.
- Linux flake checks remain green.
- devenv tasks run check:lint passes.
